Consello da Abogacía Galega

v0.3  ·  Autor: Jose Ferro

Qué es. Un panel persistente con la biblioteca compartida de prompts de IA y de documentos de referencia del Consello da Abogacía Galega, anclado junto a la página en la que estás trabajando.

Prompts (azul). Sube un archivo prompts.json, marca uno o varios prompts y combínalos.

Documentos (ámbar). Sube PDF, Word, Excel, ODS, ODT, texto plano o archivos .eml: su texto se extrae automáticamente. Marca uno o varios para incluirlos junto a tus prompts, o pulsa «Seleccionar todos» para marcarlos todos de una vez.

Combinar y copiar. Todo lo marcado — prompts y/o documentos — se une en un único bloque de texto, se copia al portapapeles y se inserta en el campo activo de la página que hay detrás de este panel.

Tamaño de letra. Los botones A− y A+ de la cabecera reducen o amplían toda la interfaz; pulsa el porcentaje para volver al 120 %. El tamaño elegido se recuerda entre sesiones.

Prompts compuestos. Un prompt puede "incluir" otros prompts por su nombre (se define al añadir un prompt): su texto se añade automáticamente allí donde se use ese prompt.

Limitaciones. Los PDF escaneados (imágenes sin capa de texto) no se pueden leer. Los archivos .msg de Outlook no se admiten: usa .eml o .txt. El soporte de .eml es básico (solo texto plano).

Estructura del archivo JSON

El archivo puede ser un objeto con la lista prompts (y, opcionalmente, un bloque metadata), o directamente una lista de prompts. Todas las claves se aceptan en español o en inglés (se indican como español / inglés).

Claves de cada prompt

  • texto / text obligatoria — el texto del prompt. Es la única clave imprescindible.
  • nombre / name — nombre que se muestra en la lista. Si falta, se usa "Prompt N". Importante: es también la referencia que usan otros prompts para incluirlo.
  • autor / author — autor del prompt. Alimenta el filtro por autor y su contador.
  • fecha / date — fecha de creación del prompt (p. ej. 2026-08-01).
  • categoria / category — categoría. Si algún prompt la tiene, la lista se agrupa en carpetas desplegables.
  • comentarios_del_autor / author_comments — nota del autor sobre para qué sirve el prompt (se muestra en cursiva bajo el nombre). No obligatoria.
  • incluye / includes — lista de nombres de otros prompts cuyo texto se añade tras el de este (prompts compuestos). No obligatoria.

Claves del bloque metadata (opcional)

  • nombre_archivo / file_name — nombre del archivo (se muestra bajo el título).
  • fecha_creacion / creation_date — fecha del archivo (se muestra bajo el título).
  • creado_por / created_by — quién preparó el archivo.
  • proyecto / project y total_prompts — se leen y se conservan al descargar, pero no se muestran.

Si no hay metadata, se usan el nombre y la fecha de modificación del propio archivo.

Otros sinónimos aceptados

  • nombre: prompt_name, title · texto: prompt_text, content
  • autor: prompt_author · fecha: date_of_creation, created_at
  • categoría: categoría, prompt_category · comentarios: comentarios, comments
  • incluye: include, composed_of

Ejemplo

{
  "prompts": [
    {
      "nombre": "Resumir artículo",
      "fecha": "2026-08-01",
      "autor": "Alex",
      "categoria": "Redacción",
      "comentarios_del_autor": "Para sacar 3 ideas clave.",
      "incluye": ["Tono corporativo"],
      "texto": "Resume el siguiente artículo en 3 puntos."
    }
  ],
  "metadata": {
    "nombre_archivo": "prompts.json",
    "fecha_creacion": "2026-08-05",
    "creado_por": "Jose Ferro",
    "proyecto": "Consello da Abogacía Galega",
    "total_prompts": 1
  }
}

Ctrl/Cmd+clic para seleccionar varios. Su texto se añade después del texto propio de este prompt.
